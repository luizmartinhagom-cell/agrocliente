# AgroClientes CRM

CRM para representantes comerciais do agronegócio.

## Como instalar como app no celular

### iPhone (iOS 16+)
1. Acesse o link pelo **Safari** (obrigatório)
2. Toque no ícone de compartilhar **⎙** (parte de baixo da tela)
3. Role e toque em **"Adicionar à Tela de Início"**
4. Toque em **"Adicionar"** no canto superior direito
5. O ícone aparece na tela inicial como um app normal

### Android
1. Acesse o link pelo **Chrome**
2. Toque no menu **⋮** (3 pontos)
3. Toque em **"Adicionar à tela inicial"**
4. Toque em **"Adicionar"**

## Funcionalidades
- Dashboard gerencial com indicadores
- Cadastro de clientes com fazenda e localização
- Planejamento semanal de visitas
- Agenda com filtro por data
- Histórico completo de visitas
- Mapa com rota otimizada
- Backup e restauração de dados
- Exportação para Excel
- Funciona offline
